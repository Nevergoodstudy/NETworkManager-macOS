## English

The roadmap has 16 items. Seven working, locally checked implementation slices have been delivered within T01, T02 and T03: typed TCP results/evidence, bounded process execution with Traceroute adoption, explicit Connections/Listeners results, ARP/Wi-Fi collection states, visible per-target IP scan setup failures, live IP/TCP batch progress with in-flight cancellation, and separate system-resolver versus specified-server DNS modes. No whole backlog item has yet met all acceptance criteria.

Primary implementation covers 3/16 tasks (18.75%) and 3/5 P0 tasks (60%). These are coverage ratios, not percentages of engineering work completed. T15 and T16 have supporting validation or local concurrency improvements. Eleven items have no new implementation in this roadmap yet. Research and bilingual planning have been delivered separately from feature acceptance.

The seven implementation slices across T01, T02 and T03 are included in the PR #20 update with bilingual implementation records. Coverage is 3/16 because three main items have active implementation; it is not an overall completion percentage. Full acceptance remains tracked under issues #14, #15 and #16. On 2026-11-11 the complete `swift run --package-path macos NMTest`, `NMCheck`, `NETworkManagerMac` Debug build, `NMCP` Debug build and MCP loopback integration test passed on arm64 macOS 27.2.1 (26B131) with Swift 6.4.2. NMTest includes local ARP, system_profiler and DNS-mode fixtures. Lookup UI automation, VPN/split-DNS real-network checks and signed-identity permission tests remain open. PR #20 is the source of truth for GitHub check status.
