## 中文

本批代码和本机验证已纳入 PR #20；VPN split DNS、`.local`、多接口与 IPv6-only 环境仍待验收。

DNS Lookup 页面和 MCP `dns_lookup` 现在明确提供两种模式：

- **系统解析**使用已有的 macOS DNS-SD 地址解析器处理 A/AAAA。macOS 可按当前网络配置选择 resolver。DNS-SD 不提供记录 TTL，因此界面显示未知，MCP 返回 `null`。
- **指定服务器**向用户给出的 DNS 服务器发送原始记录查询，保留 MX、TXT 等记录类型以及 UDP 截断后的 TCP 回退。此模式必须填写服务器。

系统模式不再读取 resolver 列表后固定选择第一台服务器来代替系统解析；空列表也不会静默回退到 1.1.1.1 或 8.8.8.8。MCP 请求包含 `mode` 和选择的 `server`，并拒绝系统模式下的非 A/AAAA 查询以及矛盾参数。旧调用若提供 `server` 但未提供 `mode`，仍按指定服务器模式处理。

resolver 清单解析会保留完整 IPv6 地址和接口 scope，并有 fixture 覆盖重复项和空配置。清单只供查看，不代表 macOS 分域 resolver 策略；实际系统查询走 DNS-SD。系统解析结果不填造 TTL。

## English

This implementation and its local checks are included in PR #20. VPN split DNS, `.local`, multiple interfaces and IPv6-only networks remain to be accepted.

DNS Lookup and the MCP `dns_lookup` tool now expose two distinct modes:

- **System resolution** uses the existing macOS DNS-SD address resolver for A/AAAA. macOS can apply its network resolver policy to the lookup. DNS-SD does not expose record TTL, so the UI shows it as unknown and MCP returns `null`.
- **Specified server** sends a raw DNS record query to the server supplied by the user. It retains MX, TXT and other supported record types, including TCP fallback for truncated UDP responses. A server is required in this mode.

System mode no longer reads a resolver list and sends the query to its first entry as if that were system resolution. An empty list no longer triggers a silent fallback to 1.1.1.1 or 8.8.8.8. MCP requests include `mode` and the selected `server`; mismatched parameters and non-address record types in system mode are rejected. For compatibility, a request that supplies `server` without `mode` is treated as specified-server mode.

Resolver-list parsing preserves full IPv6 addresses and interface scopes. Fixtures cover duplicate entries and empty configuration. The list is informational only and does not represent macOS per-domain resolver policy; actual system lookups still use DNS-SD. The implementation does not fabricate a TTL for system results.

### Local verification

- `swift run --package-path macos NMTest`: passed. Covers IPv4 and full IPv6 resolver-list parsing, deduplication, no invented public resolver for empty configuration, explicit-server enforcement for raw queries, system-mode `localhost` A/AAAA queries, and rejection of MX in system mode.
- `swift build --package-path macos --product NETworkManagerMac -c debug`: passed.
- `swift build --package-path macos --product NMCP -c debug`: passed.
- `python3 macos/Scripts/test-mcp.py --server macos/.build/out/Products/Debug/NMCP`: passed, using only `localhost` and UDP loopback fixtures.
